Getting started

Three steps to get started

Join the waitlist and we'll set up an onboarding call to do the following.

01

Install Rao

Use the desktop app on Mac or Windows, or run Rao on your institution's cluster.

02

Add your project

Point Rao at a project folder and connect Google Docs, Sheets, GitHub, or Notion. It builds your research memory on its own from there.

03

Keep working

Chat with Rao, connect the AI tools you already use, and read your digest each week. The memory updates as you go.
