Getting started

Rao is a research collaborator that remembers your project and works on it alongside you. This page covers what Rao does and where to install it.

What Rao does

  • 01 Autoresearch Rao tests ideas on the questions your project has left open, on a schedule you set. Results come back as a deck.
  • 02 Reports Ask for a weekly summary, a lab-meeting deck, or a write-up of one result, as slides, a doc, or Markdown. Each claim cites the notebook, note, or commit behind it.
  • 03 Subagents Hand a question to a subagent and keep working. Rao can split one question across several subagents in parallel: one searches the literature, another refits the data.

Also in Rao

  • The digest. New papers matched to your open threads, every night. Also by email or Slack.
  • Compute management. Launch and watch jobs on a VM or cluster.
  • Third-party agents. Connect Claude Code, Codex, and Cursor, and see what their sessions did.
  • State of the project. Where the project stands, its open threads, and a daily log.
  • Knowledge base. Every source Rao has read for the project.
  • MCP and agent switching. Move a task between agents without explaining it again.

Rao runs on your machine. Your research stays local unless you choose to share it (see the FAQ).

Pick a surface and install it

Most people start with the desktop app. Install the CLI if you work in a terminal or on a cluster, and the extension if you live in VS Code. You can install more than one; they share the same research memory.

Desktop app

The desktop app lives in your menu bar (macOS) or system tray (Windows, and Linux desktops that have one). Closing the window hides it; Rao keeps working in the background.

  • Projects. Open, create, or switch between projects.
  • Chats. Conversations with Tuva scoped to the open project, with citations to your own files.
  • Knowledge base. The sources Tuva has read for this project: local files, papers, and anything synced from connected apps.
  • Research memory. A daily record of what happened in the project, built from your chats, your agent sessions, and changes to your files. Browse it by day, or as a graph of connected episodes.
  • Agent sessions. The Claude Code and Codex sessions that ran in this project.
  • Digest. New papers that match what you are working on, found by a background run and summarised against your project.
  • Connected apps. Turn Tuva on for Claude Code, Codex, Cursor, and Claude Desktop. Link Notion and Google Drive so their pages become sources.
  • Updates. The app updates itself. A banner appears when a new version is ready.

Tuva CLI

The tuva command gives you Rao from the command line. It is the right choice on a server, when you work out of your terminal, or on a cluster login or compute node.

CommandWhat it does
tuvaGuided setup the first time. Once set up, shows status.
tuva start / tuva stopBring the daemon up or down. Safe to re-run.
tuva statusDaemon health and which coding agents are wired.
tuva init / tuva indexSet up the current folder as a project and build its knowledge index.
tuva chatChat with Tuva about the current project from the terminal.
tuva memoryInspect the project's memory: state, daily digests, and the episode graph.
tuva mcpTurn Tuva on or off for Claude Code, Codex, Cursor, and Claude Desktop.
tuva launchStart a coding agent session already wired to this project's context.
tuva connectorsLink Notion, Google Drive, and other external sources.
tuva doctorCheck whether this machine or cluster can run Tuva, and what to fix.
tuva feedbackSend a note or a bug report to the Tuva team.

VS Code extension

The extension puts Rao in a sidebar next to your notebooks, papers, and data. It is listed on the Marketplace as Rao: LLM Research Collaborator.

  • Chat with your project. Ask questions grounded in your notebooks, code, and the PDFs in your workspace. Citations link to the exact cell or page.
  • Work in notebooks. From any cell: Add to Chat, Debug Error, Analyze Figure, or Tag Cell so Tuva keeps it in context.
  • Read papers faster. Index a folder of PDFs and ask across them by name.
  • Agent integrations. Rao wires Claude Code and Codex to the same knowledge base.
