Getting started with Tuva

Rao is an always-on, proactive scientific collaborator that lives across the surfaces where you work, powered by research memory that learns new project knowledge as you do. This page explains what Rao does, which surface to install it on, and how to get set up.

What Rao is

Rao is a collaborator built on context. It keeps a living memory of your research, runs scientific agents on top of it, and improves the tools you already use, without you needing to change your workflow.

Point Rao at a project and it builds a persistent knowledge base of how everything fits together: scripts, data, notebooks, PDFs, meeting notes, planning documents. That knowledge base evolves as you do research. Rao can connect disparate ideas across your whole project, find the exact line or figure you need across hundreds of papers, scripts, and notes, and stay up to date on its own as your project evolves.

Rao comes with agents geared towards scientific research: a chat agent, proactive literature search, and a skill builder that teaches Rao to use scientific packages the way your project needs. You can also plug Rao's research memory into agents like Claude, Codex, and Cursor via MCP, so they understand your project without burning tokens rediscovering things you know.

Rao runs on your machine. The contents of your research and your interactions with Rao stay private and local unless you expressly share them. See the FAQ for what leaves your machine and when.

Rao is the same agent everywhere you already work. Three surfaces share one research memory:

  • The desktop app. One app to see your chats, projects, knowledge base, research memory, and daily paper digest.
  • The command line. Accessible from a terminal, a server, or an HPC cluster.
  • The VS Code extension. An extension for VS Code, allowing you to work next to your notebooks.

Pick a surface and install it

Most people start with the desktop app. Install the CLI if you work in a terminal or on a cluster, and the extension if you live in VS Code. You can install more than one; they share the same research memory.

Your first ten minutes

Point Rao at your project and keep working. It does the rest in the background, ready to collaborate when you are.

  1. Sign in.

    Enter your email and type the one-time code Tuva sends you.

  2. Point Rao at a project.

    A project is a folder on your machine: the one where your notebooks, scripts, data, and papers live. Open it in Rao.

  3. Index it.

    Rao automatically builds a knowledge graph of how your files relate, both scientifically and structurally. On a typical project this takes a few minutes.

  4. Plug in your other tools.

    Turn on Claude Code, Codex, or Cursor. They get Rao's context over MCP. Start a new agent session afterwards so it picks up the tools.

  5. Collaborate.

    Talk to Rao as you would a close collaborator. Ask it to pressure-test an idea, do the math, write a script, or find a paper. Rao learns new results and connections automatically as you go.

The desktop app

The desktop app lives in your menu bar (macOS) or system tray (Windows). Closing the window hides it; Rao keeps working in the background.

  • Projects. Open, create, or switch between projects.
  • Chats. Conversations with Tuva scoped to the open project, with citations to your own files.
  • Knowledge base. The sources Tuva has read for this project: local files, papers, and anything synced from connected apps.
  • Research memory. A daily record of what happened in the project, built from your chats, your agent sessions, and changes to your files. Browse it by day, or as a graph of connected episodes.
  • Agent sessions. The Claude Code and Codex sessions that ran in this project.
  • Digest. New papers that match what you are working on, found by a background run and summarised against your project.
  • Connected apps. Turn Tuva on for Claude Code, Codex, Cursor, and Claude Desktop. Link Notion and Google Drive so their pages become sources.
  • Updates. The app updates itself. A banner appears when a new version is ready.

The CLI

The tuva command gives you Rao from the command line. It is the right choice on a server, when you work out of your terminal, or on a cluster login or compute node.

CommandWhat it does
tuvaGuided setup the first time. Once set up, shows status.
tuva start / tuva stopBring the daemon up or down. Safe to re-run.
tuva statusDaemon health and which coding agents are wired.
tuva init / tuva indexSet up the current folder as a project and build its knowledge index.
tuva chatChat with Tuva about the current project from the terminal.
tuva memoryInspect the project's memory: state, daily digests, and the episode graph.
tuva mcpTurn Tuva on or off for Claude Code, Codex, Cursor, and Claude Desktop.
tuva launchStart a coding agent session already wired to this project's context.
tuva connectorsLink Notion, Google Drive, and other external sources.
tuva doctorCheck whether this machine or cluster can run Tuva, and what to fix.
tuva feedbackSend a note or a bug report to the Tuva team.

The VS Code extension

The extension puts Rao in a sidebar next to your notebooks, papers, and data. It is listed on the Marketplace as Rao: LLM Research Collaborator and works in VS Code and Cursor.

  • Chat with your project. Ask questions grounded in your notebooks, code, and the PDFs in your workspace. Citations link to the exact cell or page.
  • Work in notebooks. From any cell: Add to Chat, Debug Error, Analyze Figure, or Tag Cell so Tuva keeps it in context.
  • Read papers faster. Index a folder of PDFs and ask across them by name.
  • Writing assistant. Edits in your own voice, drawing on your results and notes, shown as diffs you step through.
  • Skills. Teach Tuva how your project uses a scientific package, so it stops guessing.
  • Agent integrations. One command wires Claude Code and Codex to the same knowledge base.

Coding agents and MCP

Rao shares its research memory with agents like Claude Code, Codex, and Cursor via MCP, so they understand your project without burning tokens rediscovering things you know. The MCP server is called tuva-context. Once connected, an agent can search the project, read paper sections, recall what happened in earlier sessions, and get the project's current state.

Turn an agent on from Connected apps in the desktop app, from Agent Integrations (MCP) in the extension, or with tuva mcp in a terminal. Then start a new agent session; an existing session will not pick up the tools.

Rao can also learn from your agent sessions. When you turn that on, past Claude Code and Codex transcripts for a project become part of its research memory.

Getting help

Email hello@tuva.ai. From the desktop app, use the feedback button in the account menu. From a terminal, run tuva feedback -m "...".

If something is not working, tuva doctor checks your environment and says what to fix. When you write in, include the output of tuva --version, tuva status, and tuva doctor.
