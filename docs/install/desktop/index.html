Installing the desktop app

The desktop app is the full Tuva experience in one window: projects, chats, your knowledge base, research memory, and a daily paper digest. It runs on macOS and Windows.

What you need

  • macOS (Apple silicon or Intel) or Windows 10 or later (64-bit).
  • Python 3.10 or newer. We recommend 3.12. Check with python3 --version in a terminal, and install from python.org if it is missing.
  • Internet access. The first launch downloads Tuva's backend, and chat runs through Tuva's cloud.
  • An email address on the Tuva access list.

Install on macOS
  1. Open the .dmg and drag Tuva into Applications.

    Then open it from Applications. The first launch sets up Tuva's backend, which takes about a minute, before the sign-in screen appears.

  2. Closing the window keeps Tuva running.

    Closing the window does not quit the app; Tuva keeps indexing and running background work from the menu bar.

Install on Windows
  1. Run Tuva-Setup.exe.

    If Windows SmartScreen shows a prompt, choose More info, then Run anyway. Tuva opens when the installer finishes. The first launch sets up Tuva's backend, which takes about a minute, before the sign-in screen appears.

  2. Closing the window keeps Tuva running.

    Closing the window does not quit the app; Tuva keeps indexing and running background work from the system tray.

First launch

  1. Sign in.

    Enter your email and type the one-time code Tuva sends you.

  2. Work through setup.

    Tuva then walks you through four short screens:

    • Your project: choose the folder where your notebooks, scripts, and papers live. Tuva does not copy or move anything.
    • Let Tuva work for you: run scheduled work in the background, and learn from your Claude Code and Codex sessions.
    • Connect your AI apps: tick Claude Code, Codex, Cursor, or Claude Desktop, and restart an app after connecting it.
    • Connect Notion: sign in once in your browser.

    You can change any of these later from the Memory page and Connected apps.

  3. Take the tour.

    A short walkthrough of where everything lives. You can replay it any time from the account menu.

Using it with the CLI and the extension

The desktop app, the CLI, and the VS Code extension share one daemon and one memory per project. Install any combination. If you already use the CLI, the app finds the running daemon and attaches to it.

Updates

The app checks for updates on its own. When one is ready, a banner appears at the top of the window and the update is applied the next time you restart Tuva. You never need to download a new installer.

Troubleshooting
  • The app stays on the loading screen. The first launch needs internet to fetch the backend. Check your connection, and if you are on a VPN or a corporate proxy, try without it.
  • The sign-in code never arrives. Check spam. Wait ten minutes before requesting another. If your address is not on the access list, email hello@tuva.ai.
  • My coding agent does not see Tuva. Check the agent's card in Connected apps, then start a new agent session.

To report a problem, use the feedback button in the account menu. It sends the app's diagnostics along with your note.
