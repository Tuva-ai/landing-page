Installing the VS Code extension

The extension puts Tuva in a sidebar next to your notebooks, with chat grounded in your code and papers, cell-level actions, and a writing assistant. It works in VS Code and Cursor.

What you need

  • VS Code 1.85 or later, or Cursor.
  • Internet access. The first start downloads Tuva's backend, and chat runs through Tuva's cloud.
  • An email address on the Tuva access list.

Install from the Marketplace

The extension is published as Rao: LLM Research Collaborator by Tuva AI. Rao is the name of Tuva's research agent.

  1. Open the Extensions view.

    Press Cmd+Shift+X (macOS) or Ctrl+Shift+X (Windows, Linux).

  2. Search for Tuva.

    Pick Rao: LLM Research Collaborator from publisher Tuva AI and click Install.

Or install from a terminal:

Terminal 
code --install-extension tuva.tuva-rao

Open the Marketplace listing ↗

Cursor. If the extension does not appear in Cursor's search, install it from the .vsix file instead: open the Command Palette, run Extensions: Install from VSIX..., and choose the file. Email hello@tuva.ai for the latest build.

Open Tuva

Click the Tuva icon in the activity bar, or press Cmd+Shift+T (macOS) or Ctrl+Shift+T (Windows, Linux). The panel opens in the sidebar. Use Move Tuva to Right Panel from the Command Palette if you would rather have it beside your editor.

The first time the panel opens, the extension starts Tuva's backend. This takes about a minute and only happens once. If you already use the CLI or the desktop app, the extension attaches to the daemon that is already running.

Sign in

The panel asks you to sign in. Enter your email and type the one-time code Tuva sends you. There is no password. You can also run Sign In from the Command Palette at any time.

Tuva's cloud handles the model calls, so you do not need an API key.

Set up a project

  1. Open a folder.

    A Tuva project is a folder. Open the one where your notebooks, scripts, and papers live.

  2. Initialize it.

    Run Initialize TUVA Project Here from the Command Palette, or New TUVA Project... to create a fresh folder. This writes a small project file and a .entropy folder for Tuva's memory. Your own files are never changed.

  3. Index it.

    Run Index Workspace. Tuva reads your notebooks, code, and PDFs and builds the knowledge base the chat draws on. Re-run it after adding a lot of new files.

Working in notebooks

Every notebook cell gets Tuva actions in its toolbar:

  • Add to Chat. Send the cell, or its output, to the conversation.
  • Debug Error. Send a failing cell's traceback and ask what went wrong.
  • Analyze Figure. Send a plot and ask about it.
  • Tag Cell. Keep a cell in context for the whole conversation. Tagged cells show in the panel.

Tuva also reads variables from a running Jupyter kernel, so it can answer about the data you have loaded, not just the code that loaded it.

Connect your coding agents

Run Agent Integrations (MCP) from the Command Palette. It wires Claude Code and Codex to Tuva's tuva-context MCP server so they can search your project and recall past work. Restart the agent, or open a new session, so it reloads its config.

Settings worth knowing

SettingWhat it does
entropy.modecloud (default) signs in through Tuva. local uses your own API key from a .env file.
entropy.libraryResolverUrlYour library's OpenURL resolver, so paywalled papers open through your institution.
entropy.analyticsEnabledAnonymous usage events. No chat content is ever sent.

Troubleshooting

  • The panel is blank. Run Developer: Reload Window from the Command Palette.
  • The panel spins and never loads. Run Toggle Mode (Local / Cloud) and make sure cloud is selected.
  • Requests stall or fail after a while. Your session may have expired. Run Sign Out, then sign in again, or reload the window.
  • Something is wrong with the backend. Show Shared Backend Status reports what is running. Open Shared Backend Log shows the log. Restart Backend (Fresh) starts over.
  • New files are not found. Run Index Workspace again.

To report a problem, use the feedback button in the panel or email hello@tuva.ai.
