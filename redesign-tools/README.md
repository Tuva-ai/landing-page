## Changing the diagram

The research brain diagram is inline SVG generated by `diagram/build_b.py`. Edit the lists at the top of that file (`SRC`, `AGENTS`, `TOOLS`), then:

```bash
cd redesign-tools/diagram
python3 build_b.py . paths.json   # writes brain-wide.svg (desktop) and brain-tall.svg (phones)
```

Replace the two `<svg class="rd-brain-svg" ...>` blocks in `index.html` with the new files' contents.

## Re-recording the demo video

The video is the real Tuva desktop interface (release 0.1.15), run in Chrome with fake project data (`video/mock.js`) and a scripted cursor (`video/record.mjs`). Needs Google Chrome, Node 20+, and access to the private `Tuva-ai/entropy` repo.

```bash
# 1. Build the Tuva desktop interface at the 0.1.15 release
git clone git@github.com:Tuva-ai/entropy.git && cd entropy && git checkout 9d4ac01f
cd desktop && npm install --ignore-scripts && node esbuild.renderer.js --production

# 2. Assemble the demo site: built interface + fake data + figure
mkdir -p /tmp/tuva-demo/site && cp -R dist/renderer/. /tmp/tuva-demo/site/
cp <landing-page>/redesign-tools/video/{mock.js,fig.png} /tmp/tuva-demo/site/
sed -i '' 's|<script src="./index.js"></script>|<script src="./mock.js"></script><script src="./index.js"></script>|' /tmp/tuva-demo/site/index.html

# 3. Serve it and record
(cd /tmp/tuva-demo/site && python3 -m http.server 8790 &)
cd <landing-page>/redesign-tools/video && npm install
node record.mjs && node encode.mjs ../../tuva-demo.mp4
```

- **What's on screen:** the project, files, digest paper, chat text and the agent's result all live in `video/mock.js` (search for `DIGEST_ITEMS`, `sendMessage`, `TASK`, `HEADLINE`, `stateText`).
- **What the cursor does and the timing:** `video/record.mjs`. Each scene is a commented block.
- **The agent's figure:** edit `video/fig.html`, then run `node fig.mjs` and copy the new `fig.png` into the demo site.
- **The project is fictional** (soybean drought H3K27me3 study). The digest paper and its authors are invented.
